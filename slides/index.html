Each 75-minute block is three to five short decks rather than one long one, so each can be read in a sitting. The syllabus says which decks belong to which session; the labs page has the matching notebooks.

Every number on these slides came from code that ran. Sessions 3 and 4 are generated from a measurement ledger — nothing is quoted from a textbook without being reproduced, and where a source turned out to be wrong, the slide says so.

A few decks are marked In class only. They show unpublished research and are shown in class rather than posted. Ask the instructor if you need them.
