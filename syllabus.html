Prerequisites

The first-year Ph.D. macroeconomics sequence (or equivalent), including dynamic optimization. Programming experience helps but is not required: Python is taught from the ground up in Session 3, and a setup lab is posted before then. Students from other fields are welcome with the instructor's consent.

Learning objectives

  1. Build and characterize the workhorse models of modern macroeconomics — growth, incomplete markets, aggregate risk, overlapping generations, optimal policy.
  2. Solve them numerically, and know which method suits which problem.
  3. Verify a computed answer: benchmark it, bound its error, and report the accuracy with its cost.
  4. Use machine learning and AI where the classical methods run out, and know where they do not help.
  5. Carry out a small replication-and-extension project end to end, with code that runs.

Use of AI tools

AI assistance is allowed and expected. You remain responsible for every number you report. Submit an AI_LOG.md with each assignment recording how you used it. The validation is the part you cannot delegate — and it is what the course is actually about.

The reporting standard

Every computational result in this course is reported with: the method; the grid (points, spacing, bounds); the chain and its implied persistence and standard deviation; the tolerance; the dtype; the maximum and mean Euler residuals on points not used to solve; and the wall time with the hardware. A number without these is not yet a result.
