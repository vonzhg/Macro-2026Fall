Labs

The notebooks ship with no stored output, on purpose. You are meant to produce the numbers, not read them. Every cell runs on a laptop CPU in well under a minute; no GPU is needed in this course before Session 7.

Getting set up

git clone https://github.com/vonzhg/Macro-2026Fall.git
cd Macro-2026Fall
conda create -n econ282e python=3.11 -y
conda activate econ282e
pip install -r labs/requirements.txt
jupyter lab

Or use any environment that satisfies requirements.txt. GitHub renders .ipynb files in the browser if you only want to read one.

Notebooks

Lab 0 — Getting Started Available Download .ipynb

Posted before Session 3. Installs the tools, verifies the environment, writes a first program, and solves the Solow model against its closed form. Start here if you have never used Python.

Lab 3 — Python and Value Function Iteration Available Download .ipynb

Session 3 (Oct 8). Python and NumPy essentials; the GrowthModel class; VFI and time iteration, both graded against the Brock–Mirman closed form; convergence and accuracy diagnostics; a dependency-free HP filter; a first look at autograd. Homework 1 Part A starts from this lab.

Lab 4 — Numerical Methods Available Download .ipynb

Session 4 (Oct 15). A root-finder bake-off with measured convergence orders (1, 1.618, 2); golden section; interpolation shape tests and Smolyak sparse grids; quadrature; Tauchen against Rouwenhorst at ρ = 0.9, 0.95, 0.99; Howard and EGM on the quarterly RBC model; and the deck 4.B5 worked example end to end.

Labs 5–10 In preparation

Perturbation and projection; Krusell–Smith; neural-network solvers; reinforcement learning; text as data; an agentic research workflow. Posted as each session is built.

If a cell fails, check the package versions first (pip install -r requirements.txt). Everything is offline-friendly except pandas-datareader, which fetches FRED data in one optional section of Lab 3.
